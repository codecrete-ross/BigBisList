# Big BiS List 0.14.0

Addon behavior changes in the 0.14.x releases, newest first. Each section describes changes introduced in that version.

## 0.14.0 - 2026-09-05

- Reorganized the window around character context and task tabs, with a phase chooser that marks live content and nearby Current Spec and Current Level controls.
- Added Comfortable and Compact table densities, clearer utility icons, vertically centered rows, persistent selection, and one combined Source column for acquisition information.
- Moved advanced filters into a pop-out that preserves list space. Each workspace keeps its own filters, with removable filter chips, clearable search, and accurate reset behavior.
- Reworked Details with fixed item identity and actions, readable acquisition steps and requirements, alternative routes, and aligned phase rankings. Sections start expanded and remain collapsible.
- Kept Details beside the list at supported window widths, with Back to list when the screen is too narrow, and improved toolbar wrapping and scroll restoration.
- Added collapsible list sections and activity grouping for Upgrades and Wishlist. Wishlist rows now show concise relevance summaries, with complete rankings in Details.
- Rebuilt My Gear as a two-column equipment overview with direct Find upgrades actions and explicit empty or two-handed slots. Enhancements has an All, Gems, Enchants, and Consumables switcher and distinguishes unused alternatives from missing enhancements.
- Made item icons and informational cells open Details consistently, with wishlist stars, item action menus, and Undo for hiding or removing saved items. Shift-click linking and Ctrl-click preview remain available.
- Organized Settings into Appearance, Tooltips, and Hidden Items. Ownership feedback distinguishes unchecked bank contents, and tooltip details expand with Alt while hovering.
- Replaced ambiguous future-use counts with clear, phase-specific recommendation text.
